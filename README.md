# 🚚 Logistics Dashboard

This project delivers a complete dashboard built with **Power BI**, focused on **logistics and fleet management**, using structured data from vehicle registration and freight operations.

## 📁 Data Sources

- `CadastroVeiculos.xlsx`: Contains registration data for each vehicle in the fleet, including type, capacity, plate number, and assigned region.
- `Fretes.xlsx`: Includes freight records such as origin, destination, distance, freight cost, delivery time, driver, and status.

## 🎯 Objectives

- Monitor freight operations and costs  
- Track delivery performance by region and time  
- Evaluate vehicle utilization and workload  
- Identify cost-saving opportunities  
- Improve decision-making in logistics planning

## 📊 Key Metrics

- 🚛 **Total Deliveries Completed**  
- ⏱️ **Average Delivery Time**  
- 💸 **Freight Cost per Kilometer**  
- 📍 **Top Origins and Destinations**  
- 🛑 **Delayed or Failed Deliveries**  
- 🧾 **Total Freight Cost per Month**  
- 🚦 **Vehicle Utilization Rate**

## 📌 Dashboard Features

- Filters by date, region, vehicle, driver, and delivery status  
- Maps with delivery flows and regional performance  
- Cost analysis with trends and averages  
- Performance indicators by vehicle and driver  
- Visual breakdown of delivery types and status

## 🧠 Key Insights

- The **Southeast region** concentrates the highest volume of deliveries and costs, requiring special attention for route optimization.  
- **Vehicle [ABC-1234]** stands out with the highest number of trips and consistent delivery times, indicating good reliability.  
- Deliveries delayed by more than **2 days** are mostly related to **routes over 800 km**, suggesting a review of transit expectations.  
- **Freight cost per km** is higher for **small vehicles**, suggesting better route allocation by vehicle type could reduce costs.

## 🛠️ Tools Used

- **Power BI Desktop**: Dashboard design and data modeling  
- **Excel**: Raw data formatting and structuring  
- **DAX**: Custom metrics and calculations
